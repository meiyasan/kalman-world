1"""The toy model from Python: written in C++ and written in Python, on the same readings.
2
3The cooling-coffee model exists twice, stating the same physics:
4``examples/cxx/toy_plugin.cc`` in C++ and ``examples/python/toy_model.py`` in
5Python. ``examples/cxx/toy_sensor.cc`` simulates a test sensor with the C++
6one, filters the readings and writes two CSV files. This script filters the
7*same readings* three ways and compares each with what the C++ program wrote:
8
91. the model written in C++, loaded by name: ``model.filter(readings)`` hands
10 the whole pass to C++, so this is the C++ program's own computation;
112. the model written in Python: the same C++ filter runs the pass and calls
12 back into the Python ``f`` and ``h`` at each step;
133. the model written in Python with the C++ library left aside
14 (``python_reference()``): the Python loop and the Python arithmetic, the
15 reference the framework's tests compare against.
16
17It prints how far apart they are, how long each took, and what the filter
18learned.
19
20 make build && make examples # builds the model and the C++ program
21 ./var/build/bin/toy_sensor # writes toy_sensor.csv, toy_estimate.csv
22 python examples/python/toy_sensor.py # reads them from the current directory
23 python examples/python/toy_sensor.py --plot # also saves toy_sensor.png
24"""

74 def timed(run, repeat=3):
75 best = float("inf") # the best of a few runs: the first one loads and warms up
76 for _ in range(repeat):
77 start = clock.perf_counter()
78 record = run()
79 best = min(best, (clock.perf_counter() - start) * 1e3)
80 return record, np.asarray(record.xk).reshape(len(readings), 2), best
