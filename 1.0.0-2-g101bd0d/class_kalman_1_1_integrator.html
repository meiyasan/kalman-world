Detailed Description

The time-stepping scheme — WHEN, within one dt.

An integrator advances a state one step, x(t) → x(t + dt), given a continuous derivative xdot = f(x, u, t). It is the counterpart of Kalman::Engine for the deterministic mean: an ODE model declares which one it wants and overrides Kalman::Model::Derivative(), and Model::f() then steps it; a field solver composes one for its time march.

Explicit schemes expose their Butcher tableau, and RungeKuttaStep() runs any such tableau on any state type with += and scalar * — a Kalman::Vector or a Kalman::Grid — so the same integrator drives both an ODE and a spectral field without a scheme being written twice.

Integrators own no run state. Mirrors modules/framework/integrator.py.
