Detailed Description

EKF GPS positioning with togglable relativistic clock corrections.

Parameters
----------
sensor_id : str
    Receiver name.
receiver_lat, receiver_lon : float
    Receiver geodetic latitude / longitude [deg] (spherical Earth).
n_sat : int
    Number of (highest-elevation, visible) satellites to use.
fs : float
    Measurement rate [Hz].
pseudorange_uncertainty : float
    Pseudorange noise std [m].
process_uncertainty : float
    Position random-walk std [m/sqrt(s)] (the receiver is nearly static).
clock_drift_uncertainty : float
    Random-walk std of the clock drift [m/s per sqrt(s)]. The simulated receiver clock
    is ideal, so the default is small; a quartz receiver clock needs about 0.1.
apply_relativistic : bool
    If True, :meth:`preprocess` removes the relativistic terms from the pseudoranges
    before filtering (toggle this to compare before/after).

Geometric/position/horizontal/vertical **dilution of precision** over time from the
*visible* satellites' geometry → dict of ``(N,)`` arrays (NaN when < 4 are in view).

DOP multiplies the per-satellite ranging error into position error: e.g. the expected
horizontal error is ``HDOP · σ_pseudorange``. It is the single number that says how good
the current sky geometry is for a GPS user — and it spikes whenever satellites set.

395 def dop(self, t):
396 """Geometric/position/horizontal/vertical **dilution of precision** over time from the
397 *visible* satellites' geometry → dict of ``(N,)`` arrays (NaN when < 4 are in view).
398
399 DOP multiplies the per-satellite ranging error into position error: e.g. the expected
400 horizontal error is ``HDOP · σ_pseudorange``. It is the single number that says how good
401 the current sky geometry is for a GPS user — and it spikes whenever satellites set."""
402 t = np.atleast_1d(np.asarray(t, float))
403 pos = self.constellation.positions(t) # (N, M, 3)
404 los = pos - self.receiver_ecef[None, None, :]
405 e = los / np.linalg.norm(los, axis=2, keepdims=True) # unit line-of-sight (N, M, 3)
406 vis = self.visible_mask(t)
407 out = {k: np.full(len(t), np.nan) for k in ("gdop", "pdop", "hdop", "vdop")}
408 for k in range(len(t)):
409 m = vis[k]
410 if m.sum() < 4:
411 continue
412 G = np.column_stack([e[k, m], np.ones(int(m.sum()))]) # rows [ex,ey,ez,1]

417 # rotate the position block into East/North/Up to split H/V DOP

419 out["gdop"][k] = np.sqrt(np.trace(Cov))
420 out["pdop"][k] = np.sqrt(np.trace(Cov[:3, :3]))
421 out["hdop"][k] = np.sqrt(Cenu[0, 0] + Cenu[1, 1])

331 """Generate ``(N, n_sat)`` pseudoranges from the true receiver position, with the
332 relativistic terms (eccentricity + secular) and Gaussian noise baked in."""
333 if seed is not None:
