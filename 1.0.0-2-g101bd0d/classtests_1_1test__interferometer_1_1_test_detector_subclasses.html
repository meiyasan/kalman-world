Synthetic K1 O3GK-like signal with peaks inside the catalog bands.

Defaults use Moisset et al. 2025 parameters: f0=167.5 Hz, B=0.136 →
partials at ~178.5, ~416, ~749 Hz (Mode 1/2/3 catalogue band centres).
Q=200 is artificially low (real K1 Q ~ 10^3-10^4) so FWHM ~ f/Q ~ 1-4 Hz
is resolvable by 1-Hz Welch and produces a single clean peak per band.

366 Defaults use Moisset et al. 2025 parameters: f0=167.5 Hz, B=0.136 →
367 partials at ~178.5, ~416, ~749 Hz (Mode 1/2/3 catalogue band centres).
368 Q=200 is artificially low (real K1 Q ~ 10^3-10^4) so FWHM ~ f/Q ~ 1-4 Hz
369 is resolvable by 1-Hz Welch and produces a single clean peak per band.
370 """
371 from modules.apps.resonators.oscillators import partial_frequencies
372 rng = np.random.default_rng(seed)
373 N = int(fs * T)
374 t = np.arange(N) / fs
375 freqs = partial_frequencies(f0, B, n_harmonics)
376 x = 1e-4 * rng.standard_normal(N)
377 Q = 200.0
378 for f in freqs:
379 A = rng.uniform(0.5, 1.5)
380 x += A * np.exp(-np.pi * f / Q * t) * np.cos(2 * np.pi * f * t)
381 return x, fs, freqs
