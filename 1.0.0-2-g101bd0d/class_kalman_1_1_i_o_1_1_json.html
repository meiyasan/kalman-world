Detailed Description

A small JSON value: enough to write and read a model file.

The core has no dependency, so it carries its own reader and writer. It is not a general JSON library: it holds null, booleans, numbers (as double), strings, arrays and objects (which keep the order their keys were set in), reads standard JSON and writes numbers with 17 significant digits, so a double goes to a file and back unchanged.

libKalmanNet uses nlohmann_json for the servers; this is for the files the core itself reads and writes (Kalman::IO::ModelFile).
