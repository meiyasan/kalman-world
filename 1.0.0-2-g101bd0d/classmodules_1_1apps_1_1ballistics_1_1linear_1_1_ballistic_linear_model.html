Maximum height of the constant-acceleration path and the time to reach it.

The height z(t) = z + ż·t + ½·z̈·t² peaks where the velocity vanishes, at
``t* = −ż / z̈`` (needs z̈ ≠ 0; t* is negative if the body is already past its
peak), giving ``z* = z − ż² / (2·z̈)``. With ``cov`` given, returns 1-σ bars too.

Returns an :class:`ApexEstimate` (time, height, time_std, height_std);
``state`` defaults to the model's initial state (the nominal launch).

Time at which the trajectory crosses ``level`` (default 0) coming down.

Solves ½·z̈·t² + ż·t + (z − level) = 0 and returns the future **descending**
root (the "hitting time"). With ``cov`` given, the 1-σ time uncertainty is
propagated via the implicit derivative  dt/dx = −[1, t, ½t²] / v_impact.

Returns an :class:`ImpactEstimate` (time, speed-at-impact, time_std). Raises if
the path never reaches ``level`` (negative discriminant) or only in the past.

137 def impact_time(self, state=None, cov=None, level=0.0):
138 """Time at which the trajectory crosses ``level`` (default 0) coming down.
139
140 Solves ½·z̈·t² + ż·t + (z − level) = 0 and returns the future **descending**
141 root (the "hitting time"). With ``cov`` given, the 1-σ time uncertainty is
142 propagated via the implicit derivative dt/dx = −[1, t, ½t²] / v_impact.
143
144 Returns an :class:`ImpactEstimate` (time, speed-at-impact, time_std). Raises if
145 the path never reaches ``level`` (negative discriminant) or only in the past.
146 """
147 z, v, a, P = self._zva(state, cov)
148 c = z - level
149 tol = 1e-9
150 if a == 0.0: # constant-velocity fallback
151 if abs(v) < tol:
152 raise ValueError("Static state never crosses the level.")
153 roots = [-c / v]
154 else:
155 disc = v * v - 2.0 * a * c
156 if disc < 0.0:
157 raise ValueError(f"Trajectory never reaches level={level} (no real crossing).")
158 sq = float(np.sqrt(disc))
159 roots = [(-v + sq) / a, (-v - sq) / a]
160 # prefer a future, descending (velocity < 0) crossing; else any future root
161 descending = [t for t in roots if t > tol and (v + a * t) < 0.0]
162 future = descending or [t for t in roots if t > tol]
163 if not future:
164 raise ValueError("No positive-time crossing of the level.")
165 t = min(future)
166 v_imp = v + a * t
167 t_std = None
168 if P is not None and abs(v_imp) > tol:
169 J = -np.array([1.0, t, 0.5 * t * t], dtype=self.dtype) / v_imp
170 t_std = float(np.sqrt(max(J @ P @ J, 0.0)))
171 return ImpactEstimate(t, v_imp, t_std)
