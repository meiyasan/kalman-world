Detailed Description

What a model, engine or filter says about itself.

The C++ counterpart of the NAME / DESCRIPTION / VERSION class attributes that modules/framework/abstract/metadata.py gives every role. They are what a catalogue, a log line or an error message quotes, so they belong to the type rather than to the instance — Kalman::Model additionally carries an instance Name() — whatever the application called that particular system — which is a different thing from its Title() ("Kalman Model").
