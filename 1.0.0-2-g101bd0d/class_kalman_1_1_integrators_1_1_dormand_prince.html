Detailed Description

Adaptive RK45.

Step() advances one outer step dt by as many substeps as the local error tolerance requires, so a fast-varying f is resolved without the caller shrinking dt. The fifth-order solution is returned; its fourth-order companion drives the step-size control. GetTableau() hands out the fifth-order weights, which is what a field solver uses as a fixed-step RK5 (per-member adaptivity makes no sense for a batched ensemble). Mirrors integrators/dormand_prince.py.
