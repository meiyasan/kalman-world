Detailed Description

Second-order finite-difference 2-D field solver — the bounded-domain kind.

Where the spectral solver needs a regular periodic mesh, this one works on any regular rectangular grid with a choice of boundary condition — periodic, Dirichlet (pinned to a value outside) or Neumann (zero gradient) — so walls and fixed values are representable. Central stencils for the gradient and the 5-point Laplacian; the time march is the composed Kalman::Integrator, through the same tableau path as the spectral solver.

A subclass supplies the physics through RHS() in real space. The built-in default is diffusion, df/dt = nu Laplacian(f), which makes the class usable on its own. Mirrors modules/framework/solvers/finite_difference.py.
