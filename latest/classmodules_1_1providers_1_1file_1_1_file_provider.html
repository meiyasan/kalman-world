Detailed Description

Load a measurement set (and optional truth) from a file.

- ``.npz`` — keys ``zk`` (required) and optionally ``xk``/``time``;
- ``.npy`` — a single ``(T, m)`` measurement array;
- ``.json`` — ``{"zk": [...], "xk": [...]?, "time": [...]?}``;
- ``.csv``  — a numeric table taken as ``zk``.
