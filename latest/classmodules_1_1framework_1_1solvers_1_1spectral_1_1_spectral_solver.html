``n`` is the grid: an ``int`` for a square ``n×n`` mesh, or
``(ny, nx)`` for a **rectangular** one.  ``length`` is the physical
domain size — a scalar or ``(Ly, Lx)`` — so wavenumbers are scaled
``2π/L`` (default ``2π`` reproduces integer wavenumbers exactly).

Spectral discretization requires a **regular periodic** mesh; bounded /
irregular grids are the job of the finite-difference/volume/element
solver kinds.

116 def _rk_step(rhs, x, dt, tableau):
117 """One explicit Runge–Kutta step from a Butcher ``tableau`` (c, A, b),
118 so *any*
119 explicit integrator drives the spectral field uniformly."""
120 c, A, b = tableau
121 ks = []
122 for i in range(len(c)):
123 if i == 0:
124 xi = x
125 else:
126 acc = A[i][0] * ks[0]
127 for j in range(1, i):
128 acc = acc + A[i][j] * ks[j]
129 xi = x + dt * acc
130 ks.append(rhs(xi))
131 out = b[0] * ks[0]
132 for i in range(1, len(b)):
133 out = out + b[i] * ks[i]
134 return x + dt * out
