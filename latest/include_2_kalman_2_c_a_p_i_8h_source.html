631/* --- kernels: the framework's arithmetic for a model that lives elsewhere ---
632 *
633 * The Python engines evaluate the model themselves -- f at the sigma points, F/H/Q/R
634 * at the current point, h at every particle -- and hand the arrays here for the
635 * step: covariance prediction, the NaN-masked Joseph update, a whole linear pass,
636 * the RTS sweep, the sigma-point moments, particle weights and resampling, NIS and
637 * NEES. One crossing per step with arrays, never a callback per point. Every one of
638 * these is the same code as the C++ engines above (Kalman::Filter, Engine::Smooth,
639 * Utils::Correct, Utils::WeightedOuterSum, Utils::SystematicResample), so a Python
640 * model on these kernels and a C++ model in ROOT+ run one implementation.
641 *
642 * All arrays row-major double; dimensions n (state), m (measurement), l (control);
643 * a NaN in a measurement marks a channel that did not arrive. The void functions
644 * leave their outputs NaN and kalman_last_error() set if anything goes wrong.
645 */

720/*
721 * The ensemble (perturbed-observation) analysis, for a caller that holds the
722 * ensemble and evaluates the model itself:
723 *
724 * X: n x N members (already inflated) Y: p x N, the members in observation space
725 * R: p x p z: p (the channels that arrived) eps: p x N draws from N(0, R)
726 * rho_xy: n x p and rho_yy: p x p localization tapers, or NULL for none
727 *
728 * Writes X + K (z + eps - Y) to X_out (n x N), K = (rho_xy . P H^T) (rho_yy . H P H^T + R)^-1,
729 * with the covariances taken from the ensemble. Returns 0, or -1 (X_out is then NaN).
730 */
