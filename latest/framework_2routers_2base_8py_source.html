1"""KalmanRouter — base contract for IKF model routing.
2
3A router maps the per-step IKF quantities to updated mode probabilities::
4
5 mu = router(nis_arr, c, likelihoods)
6
7is equivalent to::
8
9 mu = router.route(nis_arr, c, likelihoods)
10
11Arguments
12---------
13nis_arr : ndarray (k+1, M)
14 NIS history up to the current step.
15
16 NIS_j = ν_j^T S_j^{-1} ν_j
17
18 where ν_j = z − h(x̂_j^−) (innovation) and S_j = H P_j^− H^T + R
19 (predicted innovation covariance). Under the correct model,
20 NIS_j ~ χ²(m) with E[NIS_j] = m. Under a wrong model NIS_j >> m.
21
22c : ndarray (M,)
23 Predicted mode probabilities from the Markov transition:
24 c_j = Σ_i Π[i,j] μ_i.
25
26likelihoods : ndarray (M,)
27 Gaussian innovation likelihood L_j = N(ν_j; 0, S_j) per model.
28
29Returns
30-------
31mu : ndarray (M,)
32 Updated mode probabilities. Non-negative and summing to 1.
33
34Anatomy of one IKF step::
35
36 ┌─────────────────────────────────────────────────────┐
37 │ 1. Markov prediction: c_j = Σ_i Π[i,j] μ_i │
38 │ 2. State mixing │
39 │ 3. Predict + update per model → ν_j, S_j, NIS_j, L_j│
40 │ 4. Router: μ = router.route(nis_arr, c, likelihoods)│ ← pluggable
41 │ 5. Combined estimate: x̂ = Σ μ_j x̂_j │
42 └─────────────────────────────────────────────────────┘
43
44The filter passes these three quantities and never sees inside the router.
45Any callable ``(nis_arr, c, likelihoods) → mu`` also works directly.
46
47The rule-based routers (Bayesian, Threshold, Hybrid) decide in C++
48(``Kalman::Routers``) when libKalman is installed; their ``_reference_route`` is
49the Python reference, which runs inside ``native.python_reference()`` and
50without the library.
51"""

57class KalmanRouter(ABC):
58 """Abstract base for IKF model routers.
59
60 Subclass contract:
61
62 * ``route(nis_arr, c, likelihoods) → mu`` — required
63 * ``fit(nis_arrays, labels, **kw)`` — default no-op
64
65 ``__call__`` delegates to ``route`` so any KalmanRouter is callable.
66
67 Example::

69 class MyRouter(KalmanRouter):
70 def route(self, nis_arr, c, likelihoods):

165 def _native_route(self, nis_arr, c, likelihoods):
166 """The C++ router's ``mu``, or ``None`` when the reference must run."""
167 c = np.asarray(c)
168 likelihoods = np.asarray(likelihoods)
169 nis_arr = np.asarray(nis_arr)
170 if any(a.dtype.kind not in "fiub" for a in (c, likelihoods, nis_arr)):
171 return None
172 M = c.size

174 return None

176 if found is None:

178 rows = self._native_rows()

181 from ..native import core
