Detailed Description

A model whose state carries some of another model's parameters, so the filter estimates them along with the motion.

Joint estimation of state and parameters by state augmentation. The inner model declares its scalars by name (Model::DeclareParameter); the joint model appends the chosen ones to the state,

x = [ s ; theta ] s: the inner state (n), theta: p parameters
s_{k+1} = f_inner(s_k, u_k, t ; theta_k)
theta_{k+1} = theta_k + w_theta, w_theta ~ N(0, diag(drift^2))
z_k = h_inner(s_k, t ; theta_k)

so the parameters are constants that may drift a little (a random walk), which keeps the filter able to move them. A parameter given a time tau wanders and comes back instead (a first-order Gauss-Markov process, for a sensor bias or a clock offset):

theta_{k+1} = mu + exp(-dt / tau) (theta_k - mu) + w_theta

with mu the value the inner model held when this one took its initial state and dt the sample period, in the model's unit of time. Its variance then settles at drift^2 / (1 - exp(-2 dt / tau)) instead of growing without bound. Each map sets the inner model's parameters to the values carried in the state, evaluates, and puts the previous values back: the inner model is left as it was found.

The Jacobian is assembled by blocks,

J = [ df/ds df/dtheta ] df/ds: the inner model's own Jacobian, at theta
[ 0 I ] df/dtheta: differenced, p extra evaluations of f

so the motion is linearised exactly as the inner model linearises it (its analytic Jacobian if it has one; the scheme it declares otherwise), and only the p parameter columns are differenced, with the inner model's scheme and step. dh/dtheta is obtained the same way.

The covariances are block-diagonal: Q = diag(Q_inner, drift^2), R = R_inner. Q_inner is asked for with the parameters of the last state stepped from, so a process noise that depends on them sees the estimate. The initial state is the inner model's, followed by the current values of the parameters; the initial covariance is diag(P0_inner, sigma^2). Both are taken at construction: set the inner model first, or call SetInitialState() and SetInitialCovariance() on this model afterwards.

The inner model is shared, not copied. The sample rate set on this model is passed on to it before each evaluation, so the two step alike.

Note
Nothing here is specific to a domain: the drag coefficient of a shell, the gain of a sensor and the damping of an oscillator are all a declared parameter of some model.
