Detailed Description

The particle filter — Kalman::Filter driven by Engines::Particle.

Forward-only: Backward() throws, because a particle cloud has no RTS smoother. Cloud() reaches the engine for the particles, the weights and the effective sample size. Mirrors modules/framework/filters/pf.py.
