Detailed Description

Executes a policy exported from the Python framework.

The general inference backend: any of the Python architectures — MLP, CNN, LSTM, Transformer — trains in modules/framework/routers/nn/ and exports to a single ONNX graph, which this runs. It is the seam between the two implementations, and a trained policy is what crosses it, not a language binding: once at load time, rather than once per step.

router = NeuralRouter(model=MLP(hidden=32), window=5)
ikf.fit(training_zk, labels)
router.export_onnx("router.onnx")
Kalman::Routers::NN::Onnx policy("router.onnx");
Kalman::Routers::Neural router(&policy, 5);
Kalman::Filters::IKF ikf(models, Pi, &router);

Note
This class is the optional part, and it is the only optional part. ONNX Runtime is reached from here and nowhere else — behind a pImpl, so the header is free of it and consumers never need it on their include path. Kalman::Routers::Neural knows nothing about ONNX; without a runtime it still works with Kalman::Routers::NN::MLP or any model you implement. Constructing this class in a build without ONNX Runtime throws, because asking for a specific graph that cannot be executed deserves an error rather than a silently different answer.
