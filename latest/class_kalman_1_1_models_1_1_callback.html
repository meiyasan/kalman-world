Detailed Description

A model whose maps are functions supplied by the caller.

This is how a model written in another language runs on the C++ engines: its f and h, and optionally their Jacobians, are plain C function pointers, each called with an opaque user pointer. The Python package builds one from a Python model's own methods, so a model defined in a notebook is filtered by the same Kalman::Filter as a model written in C++.

A function returns 0 on success. Any other value stops the pass with a std::runtime_error, so an exception raised on the other side of the boundary is reported, not swallowed.

When no Jacobian function is given the model differences f or h itself (central differences, Model::Epsilon()).

The cost is one call across the language boundary per evaluation. A model written in C++ pays none; see docs/15 for the measurements.

◆ SetNoise()

void Kalman::Models::Callback::SetNoise ( ProcessNoiseFn  processNoise,
MeasurementNoiseFn  measurementNoise 
)

Let the caller supply the noise covariances as functions.

For a noise that depends on the state or on time, or whose coupling the caller works out itself. Either may be null, which keeps the constant SetQ() / SetR() matrix. With a process-noise function L() is empty: the function returns the covariance already coupled. One filter at a time per model: the state Q depends on is the one of the last f() call.
