Detailed Description

Can the measurements tell the components of the state apart?

A question asked about a model, before any data: along the path the model follows from its initial state, how much do N measurements say about each direction of the state? The answer is the observability Gramian,

G = sum_k Phi_k^T H_k^T R_k^-1 H_k Phi_k, Phi_k = F_{k-1} ... F_0

with F_k and H_k the Jacobians along the noise-free path. It is the information the measurements carry about the initial state; a direction d with d^T G d = 0 changes no measurement, so no filter can estimate it.

The Gramian is scaled by the initial standard deviations, S = D G D with D = diag(sqrt(P0_ii)), which makes it dimensionless: an eigenvalue of S is the information gained along its direction in units of what was known to begin with. A direction is weak when its eigenvalue is below tolerance times the largest one. Each weak direction is reported with the share of every state component in it, so the answer reads "the gain and the amplitude cannot be told apart", not "rank 2 of 3".

Where this matters: a model whose state carries parameters (Models::Joint). A parameter that enters only as a product with another unknown passes every shape check and still sits on its prior for ever.

Note
Local, like every linearisation: it answers for the path from the given initial state. A system at rest may hide a parameter that motion would reveal; give a representative initial state.

double Kalman::Observability::Weakness ( std::size_t  i) const

The share of state component i in the weak directions, in [0, 1].

0: the measurements determine it. 1: they say nothing about it. In between: it is determined only in combination with the other components that share those directions.
