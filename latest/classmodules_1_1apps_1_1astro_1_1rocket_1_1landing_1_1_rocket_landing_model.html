Detailed Description

Vertical **propulsive landing** of a booster — the SpaceX "hoverslam" / suicide burn.

Same 1-D mass-burning dynamics as :class:`RocketLiftoffModel`, run the other way: the
stage falls engine-off (``v < 0``), then a **closed-loop landing burn** ignites late
and throttles to arrive at the pad near zero velocity — the late, single-shot burn
that *is* a hoverslam (there is no fuel to hover)::

    ḣ = v
    v̇ = a_T(h,v,m) − g − ½ ρ(h) (C_d A) v|v| / m
    ṁ = −a_T·m / v_e            (propellant spent ∝ thrust; 0 once tanks are dry)

The onboard guidance ``a_T`` (see :meth:`guidance`) holds the descent to a reference
profile ``v_ref(h) = −√(2·decel·h) − v_touch`` that vanishes at the pad: above it the
engine stays off and the booster free-falls; once it catches the profile the engine
fires and tracks it down. A ground radar measures **altitude only**; the EKF recovers
the unmeasured descent rate and the dwindling propellant. ``n = 3``, ``m = 1``,
``l = 0``. Seed it descending, e.g. ``initial_state([h0, -v0, m0])``.

143 def guidance(self, x):
144 """Commanded thrust acceleration ``a_T`` [m/s²] (≥ 0, upward) for state
145 ``x = [h, v, m]``: zero while above the reference descent profile (free fall)
146 or out of propellant, otherwise throttled to track it down to the pad."""
147 h, v, m = np.asarray(x, float).reshape(-1)[:3]
148 if m <= self.m_dry or h <= 0.0:
149 return 0.0
150 m_eff = max(m, self.m_dry)
151 a_max = self.thrust_max / m_eff
152 v_ref = -np.sqrt(2.0 * self.decel * max(h, 0.0)) - self.v_touch
153 a_drag = -0.5 * self._rho(h) * self.drag_area * v * abs(v) / m_eff
154 a_cmd = self.kp * (v_ref - v) + self.g - a_drag # so that v̇ → kp·(v_ref − v)

State enum — a domain enum when declared, else one synthesized from
``n`` (``X0 … Xn-1``).

The bare ``KalmanState`` has no members, which left every unlabelled
model (anything built from matrices, including a ``KalmanSpec``) with an
empty component list and therefore unplottable.  Synthesizing labels
keeps the generic path usable; a domain model overriding this property
is unaffected.

Reimplemented from modules.framework.model.KalmanModel.
