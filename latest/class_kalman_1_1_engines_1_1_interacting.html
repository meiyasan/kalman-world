Detailed Description

The predict/update step for a model with several modes (Models::Router): the Interacting Multiple Model filter of the literature.

The engine keeps one Gaussian belief per mode and the probability mu of each. One step, in the words of the contract:

predict
c_j = sum_i Pi_ij mu_i the probabilities, one step on (Markov)
x_j, P_j <- blend of every mode's belief "mixing": weights Pi_ij mu_i / c_j
x_j, P_j <- predict of mode j, with its own engine
prior = sum_j c_j (x_j, P_j) what the filter records
update
L_j, NIS_j = how well mode j explains z the likelihood of its innovation
x_j, P_j <- update of mode j, with its own engine
mu = decision(NIS so far, c, L) the router (Routers::Bayesian: mu_j ~ c_j L_j)
posterior = sum_j mu_j (x_j, P_j) the combined estimate

Mixing is what separates this from several filters run side by side: a mode that becomes relevant starts from the state the others built up. A combined covariance adds the spread of the modes' means to their covariances.

Each mode is stepped by the engine its model asks for (linear, extended, unscented, combinatorial), so a linear and a nonlinear mode can sit in one model. A mode on a sample-set engine (particle, ensemble) is refused: mixing hands each mode a Gaussian to start from, which those engines would ignore.

The belief the filter passes in is not what the engine steps from: the modes' own beliefs are, which start from each mode's initial state at Reset(). There is no smoother.

Words of this field, kept here: mode (one of the models), mixing (the blend before the prediction), mode probability (mu).

Measurement update in Joseph form; NaN channels of z are skipped.

S = H P H^T + R innovation covariance
K = P H^T S^-1 Kalman gain
x = x + K (z - h(x)) corrected mean

The residual is taken against the true (possibly nonlinear) h(x) rather than H x, which is what makes the same code correct for the extended engine.

Parameters
modelthe system.
x,Pthe predicted belief.
zthe measurement; NaN marks a missing channel.
tthe time tag of this step.
[out]xOutthe corrected mean.
[out]POutthe corrected covariance.
Returns
the number of measurement channels actually used (0 when the whole measurement was missing, in which case the belief passes through unchanged — a predict-only step).
