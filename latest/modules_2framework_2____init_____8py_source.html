1"""
2Kalman framework — the Model / Engine / Filter contracts and their concrete pieces.
3
4Layers (dependency points downward only: Filter → Engine → Model):
5- ``model.py`` : ``KalmanModel`` — the system (WHAT): f/h/F/H/B/L/M/Q/R.
6- ``engine.py`` : ``KalmanEngine`` — the algorithm (HOW): one predict/update/smooth step.
7- ``filter.py`` : ``BayesFilter`` — the workflow (WHEN): forward/backward + run state; ``KalmanFilter`` is its Gaussian family, ``ParticleFilter`` stands beside it.
8- ``models/`` : typed model bases (``LinearKalmanModel`` / ``...Extended`` / ``...Unscented`` / ``...Composite``).
9- ``engines/`` : concrete engines (``LinearKalmanEngine`` / ``Extended`` / ``Unscented`` / ``Particle``).
10- ``filters/`` : the recognisable filter names (``LinearKalmanFilter`` / ``Extended`` / ``Unscented`` / ``Particle`` / ``Ensemble`` / ``Combinatorial`` / ``Interactive``).
11- ``constants.py``: ``KalmanEngineKind`` (LINEAR/EXTENDED/UNSCENTED/PARTICLE) used to bind models↔engines.
12
13Domain applications live in ``kalman.apps``.
14"""
