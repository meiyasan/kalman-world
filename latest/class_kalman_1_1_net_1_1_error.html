Detailed Description

A refused request, with the HTTP status that says why.

Every verb of Kalman::Net::Api reports a failure by throwing this, and both servers turn it into their reply: the REST server into the status and {"detail": message}, the MCP server into a tool result marked as an error. The statuses are the ones the Python REST API uses (modules/rest/app.py):

  • 400 a bad request (malformed spec, wrong shapes, unknown model base);
  • 401 no token, or a forged, expired, malformed or revoked one;
  • 403 a good token without the scope;
  • 404 an unknown name or run;
  • 409 a name taken by a different definition;
  • 501 a verb this server does not serve (it stays in the Python server).
