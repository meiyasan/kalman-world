Detailed Description

Sequential importance resampling (the bootstrap particle filter).

The one engine that makes no Gaussian assumption at all: the belief is a cloud of N weighted samples. Predict() pushes every particle through the true f with a draw from Q; Update() reweights each by the Gaussian likelihood of the measurement under h and R, normalises, and resamples systematically when the effective sample size falls below threshold * N. Both steps hand back the weighted mean and covariance so the filter's record and diagnostics are unchanged.

It is therefore stateful — it owns the cloud for the duration of a forward pass — and Kalman::Filter calls Reset() on it when a run starts. It has no RTS smoother (HasSmoother() is false): Filter::Backward() refuses rather than pretending.

The noise source is an engine-owned Mersenne twister seeded in the constructor, never a global stream, so adding or removing another stochastic engine in the same process cannot change this one's draws.

Mirrors modules/framework/engines/particle.py.
