Animated phasor diagram for power-grid odd harmonics.

Three synchronized panels: lab-frame phasors rotating at each harmonic's own
angular frequency, the individual harmonic waveforms, and their composite vs the
ideal (fundamental-only) waveform — tied together by a moving time cursor.

Parameters
----------
f0 : float
    Fundamental frequency [Hz].
phasors : list of (V, phi)
    Amplitude [V] and phase [rad] for H1, H3, H5, … (odd harmonics, in order) —
    half-wave-symmetric grid harmonics.  ``phasors[0]`` is the fundamental H1.
colors : list of str, optional
    Per-harmonic colors.  Default: matplotlib tab10 cycle.
frames, interval : int
    Animation frame count and interval [ms] over one fundamental period.

Returns
-------
Jupyter HTML player (or raw ``FuncAnimation`` outside Jupyter) — see ``helpers.animate``.

30 import matplotlib.pyplot as plt
31 from matplotlib.patches import FancyArrowPatch
32 from ....helpers import animate
33
34 n = len(phasors)
35 if colors is None:
36 cmap = plt.cm.tab10
37 colors = [cmap(k) for k in range(n)]
38 labels_short = [f"H{2 * k + 1}" for k in range(n)]
39 labels = [f"{lbl} ({'f₀' if k == 0 else f'{2 * k + 1}f₀'})" for k, lbl in enumerate(labels_short)]
40 omegas = [2 * np.pi * (2 * k + 1) * f0 for k in range(n)]
41
42 T = 1.0 / f0
43 t_cyc = np.linspace(0, T, 500)
44 harmonic_waves = [V * np.cos(omegas[k] * t_cyc + phi) for k, (V, phi) in enumerate(phasors)]
45 v_clean = sum(harmonic_waves)
46 v_ideal = phasors[0][0] * np.cos(omegas[0] * t_cyc)
47
48 frame_t = np.linspace(0, T, frames, endpoint=False)
49
50 fig, axes = plt.subplots(1, 3, figsize=figsize)
51 fig.suptitle("Power grid phasors — amplitude, phase, and time-domain reconstruction", fontweight="bold")
52
53 # Phasor diagram — arrows rotate at each harmonic's own angular frequency. Axis is
54 # square and sized to the largest amplitude in BOTH dimensions: a rotating phasor
55 # swings through the full +/-amplitude range on y too, not just on x.
56 ax0 = axes[0]
57 ax0.set_aspect("equal")
58 Vmax = max(V for V, _ in phasors)
59 ax0.set_xlim(-Vmax * 1.15, Vmax * 1.15); ax0.set_ylim(-Vmax * 1.15, Vmax * 1.15)
60 ax0.axhline(0, color="gray", lw=0.5); ax0.axvline(0, color="gray", lw=0.5)
61 ax0.set_xlabel("Re [V]"); ax0.set_ylabel("Im [V]")
62 ax0.set_title("Phasor diagram (rotating, lab frame)")
63 arrows = []
64 for (V, phi), col in zip(phasors, colors):
65 arrow = FancyArrowPatch((0, 0), (V * np.cos(phi), V * np.sin(phi)),
66 color=col, arrowstyle="-|>", mutation_scale=14, lw=2.2)
67 ax0.add_patch(arrow)
68 arrows.append(arrow)
69 # Fixed-position readout instead of labels at each arrow tip: harmonic amplitudes
70 # vary by orders of magnitude, so tip-anchored labels collide near the origin.
71 info_text = ax0.text(0.02, 0.98, "", transform=ax0.transAxes, va="top", ha="left",
72 fontsize=7.5, family="monospace",
73 bbox=dict(facecolor="white", alpha=0.85, edgecolor="gray", pad=3))
74
75 # Individual harmonic waveforms — static curves + moving cursor dots
76 ax1 = axes[1]
77 for wave, lbl, col in zip(harmonic_waves, labels, colors):
78 ax1.plot(t_cyc * 1e3, wave, color=col, lw=1.5, label=lbl)
79 ax1.axhline(0, color="gray", lw=0.5)
80 ax1.set_xlabel("t [ms]"); ax1.set_ylabel("voltage [V]")
81 ax1.set_title("Individual harmonics")
82 ax1.legend(fontsize=8)
83 cursor1 = ax1.axvline(0, color="black", lw=0.8, ls=":")
84 dots1 = [ax1.plot([], [], "o", color=col, ms=5)[0] for col in colors]
85
86 # Composite waveform — static curves + moving cursor dot
87 ax2 = axes[2]
88 ax2.plot(t_cyc * 1e3, v_clean, color="purple", lw=2, label=" + ".join(labels_short))
89 ax2.plot(t_cyc * 1e3, v_ideal, "--", color="steelblue", lw=1, label="H1 only (ideal)")
90 ax2.axhline(0, color="gray", lw=0.5)
91 ax2.set_xlabel("t [ms]"); ax2.set_ylabel("voltage [V]")
92 ax2.set_title("Composite: distorted vs ideal")
93 ax2.legend(fontsize=8)
94 cursor2 = ax2.axvline(0, color="black", lw=0.8, ls=":")
95 dot2 = ax2.plot([], [], "o", color="purple", ms=5)[0]

97 def _draw(i):
98 t = frame_t[i]
99 tm = t * 1e3
100 lines = []
101 for k, ((V, phi), arrow, col) in enumerate(zip(phasors, arrows, colors)):
102 ang = omegas[k] * t + phi
103 x, y = V * np.cos(ang), V * np.sin(ang)
104 arrow.set_positions((0, 0), (x, y))
105 lines.append(f"{labels[k]}: V={V:>5.1f}V φ={np.degrees(ang) % 360:>5.1f}°")
106 dots1[k].set_data([tm], [x])
107 info_text.set_text("\n".join(lines))
108 cursor1.set_xdata([tm, tm])
109 cursor2.set_xdata([tm, tm])
110 v_now = sum(V * np.cos(omegas[k] * t + phi) for k, (V, phi) in enumerate(phasors))
111 dot2.set_data([tm], [v_now])
112 return tuple(arrows) + (info_text,) + tuple(dots1) + (cursor1, cursor2, dot2)
113
114 plt.tight_layout()
115 return animate(fig, _draw, frames=frames, interval=interval)
