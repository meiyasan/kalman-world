Detailed Description

u = -K (x_hat - x_ref), K from the DARE of the model's F, B, Qcost, Rcost.

The Riccati equation is solved by Algebra::SolveDARE (the recursion, then Newton steps; it agrees with scipy's solve_discrete_are, the Python reference, to rounding), and Fit() must be called before use. Mirrors controllers/lqr.py, which forwards to this class.
