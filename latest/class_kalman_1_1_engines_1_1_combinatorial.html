Detailed Description

Track finding by track following — the Belle II CKF in miniature.

Where the other engines estimate one trajectory from a time series of single measurements, this one reconstructs several tracks from an event whose every layer holds many hits. For each seed it follows the track outward layer by layer; at each layer it opens a branch per hit that passes a chi-square gate (plus a hole branch for detector inefficiency), prunes to a bounded beam of best candidates, and finally arbitrates shared hits so the reported tracks are disjoint.

A single predict/update step is not the algorithm here — the search is — so this engine offers Find() and SmoothTracks() over a whole event, and Kalman::Filters::CKF is the thin leaf that names it. The per-step arithmetic is inherited unchanged from Engines::Extended: nonlinear propagation to the next layer radius (f(x, u, t = r)), the observation map and its Jacobian, and the RTS step. The additions are the gate and the search around it.

Hyper-parameters, the counterpart of the UKF's alpha/beta/kappa:

chi2Cut per-hit chi-square gate (default: 99% of chi2(m))
maxCandidates beam width kept per seed after each layer (6)
maxHoles missed layers allowed on a track (2)
minHits minimum assigned hits to accept a track (3)
sharedHitFrac max fraction of a track's hits shared with an accepted one (0.3)
holePenalty score added per hole (default: one gate's worth)
