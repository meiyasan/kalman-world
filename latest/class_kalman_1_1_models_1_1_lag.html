Detailed Description

A model that carries its last L states along with the present one.

The state is the inner model's, L + 1 times over:

X_k = [ x_k ; x_{k-1} ; ... ; x_{k-L} ]
X_{k+1} = [ f_inner(x_k, u_k, t) ; x_k ; ... ; x_{k-L+1} ]

Each step computes the new present state and shifts the others down. Two things come of it, with no change to any filter:

  • a sensor that reports late. A sensor with a delay (Sensor::delay) reads the state as it was delay ago: its rows of the measurement are evaluated at block round(delay * fs) instead of block 0. The filter's update then corrects the past state it concerns and, through the covariance between the blocks, the present one.
  • fixed-lag smoothing. After the update at step k, block j is the estimate of x_{k-j} given the data up to k: the state j steps ago, improved by the j measurements that came after it.

The sensors are the inner model's (Model::Sensors()), added before the model is lagged; each keeps its place in z. The noise enters the present state only: Q = diag(Q_inner, 0, ...), R = R_inner. The initial state is the inner one in every block, with the inner covariance on each block and none between them. A model of matrices stays one, on the linear engine. The named parameters are the inner model's.

The inner model is shared, not copied, and steps at this model's sample rate.
