Detailed Description

Transverse charged-particle tracker on concentric layers (Belle II CDC style).

The default engine is the **combinatorial** one (track finding); the extended engine is
also allowed (single-track fit / comparison)::

    model = DriftChamberModel(n_layers=8, Bz=1.5)
    event = model.generate_event(n_tracks=3, n_background=4, seed=0)
    tracks = CombinatorialKalmanFilter(model).forward(event.hits, layer_radii=event.radii)

Defaults are close to the Belle II central drift chamber: a 1.5 T field, layers
between 20 cm and 104 cm, and a hit resolution of 130 µm.

Parameters
----------
n_layers, r_inner, r_step : layer count, innermost radius [cm] and layer spacing [cm].
Bz        : axial magnetic field [T].
q         : particle charge [e].
sigma_hit : hit resolution, a standard deviation [cm].
p_seed    : momentum guess used when seeding [GeV/c].
q_pos, q_mom : process-noise variances per layer, position [cm²] and momentum [(GeV/c)²].
step      : RK4 arc-length sub-step [cm].

Generate one event: ``n_tracks`` signal tracks + per-layer background hits.

Returns a :class:`TrackingEvent`. Each track is launched near the origin with a
random direction (``phi_range``) and transverse momentum (``pt_range``), then
propagated outward through the layers with this model's ``f``; hits get Gaussian
resolution noise and may be dropped (``efficiency`` < 1 → detector holes).
Background hits are random points on each layer (truth id ``-1``).

151
152 Returns the 4-state at the crossing, or ``None`` if the track curls back before
153 reaching it (within a generous arc-length budget)."""
154 s = np.asarray(s, dtype=float).reshape(-1).copy()
155 r0 = np.hypot(s[0], s[1])
156 if r_target <= r0 + 1e-12:
157 return s
158 budget = 4.0 * (r_target - r0) + 20.0
159 travelled = 0.0
