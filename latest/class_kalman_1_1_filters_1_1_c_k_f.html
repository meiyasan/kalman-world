Detailed Description

The combinatorial Kalman filter — track finding over an event.

Not a Kalman::Filter: its input is an event of many hits per layer, not a time series, and its output is a collection of tracks, not one record. The search — seeding, gating, branching, pruning, arbitration, and the smoother over the found tracks — is the algorithm, so it lives in Kalman::Engines::Combinatorial; this class names that engine, hands it the search hyper-parameters, and turns what it returns into records indexed by layer radius.

DriftChamber chamber(8, 0.05); // a Model that is also a Tracking::Detector
auto event = chamber.GenerateEvent(3, 4, 0);
Kalman::Filters::CKF ckf(&chamber);
Kalman::RecordCollection tracks = ckf.Find(event.hits); // one record per track
tracks = ckf.Smooth(); // RTS over each
