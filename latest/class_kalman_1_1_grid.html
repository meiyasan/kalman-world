Detailed Description

template<typename T>
class Kalman::Grid< T >

(rows, cols) cells of T, row-major, with the arithmetic a Runge–Kutta step needs and nothing else.

Kalman::Matrix is the small dense algebra type of the filters; this is the field type of the solvers, which never multiply two grids but add them, scale them and hand them to an FFT. Grid<double> is a real field (Kalman::Field), Grid<std::complex<double>> its spectrum (Kalman::SpectralField). Both feed the same generic RK step in Kalman/Integrator.h, so any explicit integrator drives any solver.
