Detailed Description

Interactive Kalman Filter — several models, one estimate.

The literature calls this algorithm the Interacting Multiple Model (IMM) filter; Kalman::Filters::IMM is kept as an alias of this class.

When no single model covers a system's whole behaviour, run all of them and carry a probability on each: a target that cruises and manoeuvres needs both descriptions, and neither alone. The IKF mixes the modes at every step so a model that becomes relevant inherits the state the others have built up, rather than starting cold. The modes themselves are yours — the framework supplies the machinery, not the regimes.

One step:

1. Markov prediction c_j = sum_i Pi(i,j) mu_i
2. State mixing x0_j = sum_i mu_ij x_i, P0_j likewise + spread
3. Per model predict + update -> nu_j, S_j, NIS_j, L_j
4. Router mu = router(nis, c, likelihoods) <- pluggable
5. Combination x = sum_j mu_j x_j, P likewise + spread

Step 4 is the only decision, and it is delegated to a Kalman::Routers::Router: classical Bayes, a NIS rule, a blend, or a policy trained in Python and run through ONNX. Everything else is fixed by the algorithm.

Kalman::Routers::Bayesian router;
Kalman::Filters::IKF ikf({&cruise, &manoeuvre}, Pi, &router);
auto record = ikf.Forward(measurements);
const Kalman::Matrix &modes = ikf.ModeHistory(); // (T, M) probabilities
