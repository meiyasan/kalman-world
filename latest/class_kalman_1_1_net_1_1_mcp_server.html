Detailed Description

The Model Context Protocol server of modules/mcp/server.py, for the verbs Kalman::Net::Api serves.

JSON-RPC 2.0: initialize, ping, tools/list and tools/call, over stdio (one message per line, RunStdio()) or over HTTP (POST /mcp of Kalman::Net::RestServer). The tools have the names, arguments and results of the Python server's (list_models, describe_model, run_filter, ...); a tool result carries the answer both as structuredContent and as JSON text.

The caller's token, first match wins, as in Python: the tool's token argument, the HTTP Authorization: Bearer header, and on stdio KALMAN_MCP_TOKEN.
