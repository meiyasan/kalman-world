Detailed Description

What a model offers the ensemble engine beyond f and h.

A model implements this next to Kalman::Model, the way a trackable model implements Tracking::Detector, and the engine finds it with a dynamic_cast. The Python hooks of the same names are forecast(X), observe(X), localization() and the noise the engine draws from Q. Each default does what the engine does without the hook.
