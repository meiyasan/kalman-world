Detailed Description

libKalman driven from a ROOT program — the integration demonstrator.

A projectile under gravity and quadratic drag, tracked by an extended Kalman filter, with the result drawn through ROOT. It exists to show three things at once:

  1. The dependency direction. This translation unit includes both <Kalman/Kalman.h> and <TGraph.h>. libKalman itself includes neither ROOT nor anything else — ROOT links it, never the reverse. That is what lets the same library also serve a non-ROOT analysis.
  2. Where physics lives. Ballistics below is an application: it subclasses Kalman::Models::Extended and encodes gravity, drag and a launch. The framework ships no such model, exactly as modules/framework/ ships none and modules/apps/ballistics/ does.

  3. Where plotting lives. Kalman::Record hands out plain arrays; this file turns them into TGraphs. The library never grew a drawing dependency to make that possible.

    source var/install/bin/thislib.Kalman.sh # or set the paths yourself ./var/build/bin/ballistics_root
