Detailed Description

Decides which model is right now — the IKF decision layer.

When one model cannot describe a system across all of its regimes — a manoeuvring target, a storm that recurves, a suspension that goes nonlinear — the answer is several models running in parallel with a probability on each. A router owns that probability update, and only that:

mu = router.Route(nis, c, likelihoods)
Parameters
nis(k+1, M) NIS history up to the current step. Under the correct model NIS_j ~ chi2(m), so E[NIS_j] = m; under a wrong one it is much larger. NIS is the feature of choice because it is dimensionless and scale-free, so it does not shift between training and inference.
c(M) Markov-predicted mode probabilities, c_j = sum_i Pi(i,j) mu_i.
likelihoods(M) Gaussian innovation likelihood L_j = N(nu_j; 0, S_j).
Returns
(M) updated mode probabilities: non-negative, summing to 1.

One IKF step, with the router as the only pluggable part:

1. Markov prediction c_j = sum_i Pi(i,j) mu_i
2. State mixing x0_j, P0_j from every mode
3. Per model predict + update -> nu_j, S_j, NIS_j, L_j
4. Router mu = Route(nis, c, likelihoods) <- pluggable
5. Combination x = sum_j mu_j x_j

Kalman::Filters::IKF passes those three quantities and never looks inside. Implementations here mirror modules/framework/routers/ one for one: Kalman::Routers::Bayesian (classical), Kalman::Routers::Threshold (rule-based), Kalman::Routers::Hybrid (a blend) and Kalman::Routers::Neural (a policy trained in Python and executed here through ONNX Runtime).

Last window rows of nis, front-padded with 1.0 (the chi2(1) mean).

Padding at the front keeps the most recent step in the last slot, so a feature vector means the same thing at step 2 as at step 2000.

Vector Kalman::Routers::Router::Normalise ( Vector  mu)

Clip to a positive floor and normalise to a probability vector.

The floor matters: a mode that reaches exactly zero can never recover, because every subsequent update multiplies it by something finite. An IKF that has written off a regime cannot switch back to it.
