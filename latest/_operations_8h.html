Detailed Description

The model operations as functions: a model made from another.

Author
Marco Meyer <marco.nosp@m..mey.nosp@m.er@om.nosp@m.u.ac.nosp@m..jp>

Each returns a model that any Kalman::Filter runs, and they nest:

auto shell = std::make_shared<MyShell>();
auto radar = Kalman::AddSensor(shell, Kalman::Sensor("doppler", doppler, R)); // one more sensor
auto model = Kalman::Joint(radar, {{"c_drag", 1e-3, 1e-6}}); // and a parameter estimated
Kalman::Filters::EKF ekf(model.get());

These share the models they are given. The methods of the same names on Kalman::Model (model.AddSensor(sensor), model.Joint({...})) borrow the model instead, for one that lives on the stack; it must then outlive the result. Python has both forms too: model.add_sensor(sensor) and add_sensor(model, sensor).
