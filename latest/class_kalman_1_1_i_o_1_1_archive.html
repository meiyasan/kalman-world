Detailed Description

Several named byte strings in one file: a zip archive, entries stored.

What keeps the parts of a model file together. The file is a standard zip archive, so unzip -l, Python's zipfile and any file manager open it. Every entry carries a CRC-32 that is checked on reading.

Entries whose name ends in .json are always stored as they are: they are the readable part. The others (tables) are compressed with zlib when the library was built with it (KALMAN_WITH_ZLIB) and it makes them smaller; otherwise they are stored. A build without zlib reads stored entries only, and says so when it meets a compressed one.
