Detailed Description

Replans a sampled control sequence at every step by Monte-Carlo rollout of the true f.

Unlike LQR — one gain from one linearisation — MPPI resolves argmin E[sum e^T Qcost e + u^T Rcost u] from scratch each tick by rolling nRollouts perturbed sequences through the model's own nonlinear f(), so any actuator limit the model enforces (ClipControl) is respected during planning. Warm-started: the nominal found at step k, shifted by one, seeds step k+1. The random stream is controller-owned and seeded. Mirrors controllers/mppi.py.

Hand the next Policy() call its perturbations instead of drawing them.

draws holds NDraws() values, already scaled by the noise sigma, in the order iteration, rollout, horizon step, command component — the order controllers/mppi.py draws them from its numpy generator, so a seeded Python controller makes the same decisions whoever runs the rollouts (as kalman_propagate takes its noise from the caller). Used once.
