Detailed Description

Standard linear Kalman step, using the model's matrices directly.

x_prior = F x + B u and z_pred = H x, read straight off Kalman::Model::F() / B() / H(). On a nonlinear model this would silently ignore the nonlinearity, so use Kalman::Engines::Extended there.
