Detailed Description

The C kernels behind the Python engines, implemented by the C++ classes.

Author
Marco Meyer <marco.nosp@m..mey.nosp@m.er@om.nosp@m.u.ac.nosp@m..jp>

Each entry point builds the C++ objects the arithmetic belongs to and runs them: a linear pass is a Kalman::Filter over Engines::Linear on a Models::Linear assembled from the matrices, an update is Utils::Correct, the RTS sweep is Engine::Smooth, the sigma-point moments are Utils::WeightedOuterSum, resampling is Utils::SystematicResample. That is the point of the file: the Python package used to carry its own C copy of this arithmetic (native/kalman.c), and a second implementation of a Kalman step is a second place for it to be wrong.
