Detailed Description

Geometric blend (log-linear opinion pool) of two routers.

mu = mu_a^(1-alpha) * mu_b^alpha / Z

At alpha = 0 it is purely the first router, at alpha = 1 purely the second. A geometric blend rather than an arithmetic one because it is conjunctive: a mode both routers dislike stays suppressed, where an arithmetic mean would let one confident router resurrect it.

The usual reason to reach for it is to keep a learned policy on a leash:

Kalman::Routers::Bayesian bayes;
Kalman::Routers::Neural learned("router.onnx");
Kalman::Routers::Hybrid router(&bayes, &learned, 0.3); // mostly Bayes
