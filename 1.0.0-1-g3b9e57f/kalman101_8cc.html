Detailed Description

The whole library in one program: simulate, filter, smooth, check.

Generates a noisy constant-velocity track, filters it, smooths it, and reports the consistency diagnostics. Nothing outside libKalman is used, so this also demonstrates that the library stands alone: no ROOT, no Eigen, no Torch.

The model is defined here, in the application, not in the library. libKalman ships no physics — a constant-velocity tracker is a domain choice, and it lives with the domain. 

make build && make examples
./var/build/bin/kalman101 > track.tsv
