Detailed Description

Where a Jacobian comes from.

The extended filter needs df/dx and dh/dx. A model declares how they are obtained, as a Kalman::DifferentiatorKind:

  • Analytic: the model gives the formula (F(), H(), or its own Jacobian()).
  • Forward: (f(x + s e_j) - f(x)) / s, one extra evaluation per component. First order in the step. What the Python framework has always used.
  • Central: (f(x + s e_j) - f(x - s e_j)) / 2s, two evaluations per component. Second order.
  • Automatic: exact derivatives by automatic differentiation. Reserved: it needs a tensor library, so it belongs to libKalmanLearn.

The step is relative: s = step * max(1, |x_j|).

The role next to it: the Integrator advances a model in time, the Solver handles space for a field, the Differentiator gives the derivatives.
