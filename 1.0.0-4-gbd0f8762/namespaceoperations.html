Detailed Description

The model operations, one after the other, on a cart.

Each operation takes models and gives back a model; the filter is always the
ordinary one. Everything is computed by the C++ library.

    add_sensor      one more sensor on the same state
    lag             the last states carried along: a sensor that reports late
    add_instrument  sensors under one name, with a calibration
    joint           a parameter estimated with the state
    compose         two systems side by side
    route           one system, two regimes

    python examples/python/operations.py

The same steps in C++: ``examples/cxx/operations.cc``.

47def simulate(model, steps, n=2):
48 """Truth and readings from the model's own f and h (noise on the first ``n`` components)."""
49 Lq = np.linalg.cholesky(model.Q()[:n, :n] + 1e-15 * np.eye(n))
50 Lr = np.linalg.cholesky(model.R())
51 x, xs, zs = np.asarray(model.x0, dtype=float).copy(), [], []
52 for _ in range(steps):
53 x = model.f(x)
54 x[:n] += Lq @ rng.standard_normal((n, 1))
55 xs.append(x.ravel().copy())
56 zs.append((model.h(x) + Lr @ rng.standard_normal((model.m, 1))).ravel())
57 return np.array(xs), np.array(zs)
