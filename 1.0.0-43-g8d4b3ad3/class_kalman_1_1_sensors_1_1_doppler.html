Detailed Description

The velocity along the line of sight, one channel: 

v_r = v . (p - at) / |p - at|
Parameters
namewhat the sensor is called.
nthe number of state components of the model it will read.
position,velocitythe indices of the position and of the velocity in the state, as many of each (1, 2 or 3 dimensions).
sigmathe standard deviation of the reading.
atwhere the sensor is; the origin when empty.

Where it is are its settings x, y, z (as many as dimensions): the model that takes it has the parameters <name>.x, ..., which Kalman::Joint can estimate. At the sensor itself the line of sight is not defined: the reading is 0.
