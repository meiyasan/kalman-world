Detailed Description

Draws truth and measurements from a model, for tests and demos.

Runs the model forward as a stochastic system rather than as an estimator: the truth is propagated through f with process noise drawn from Q, and each measurement is h(x) plus noise drawn from R. Because the same model object supplies both the data and the filter's belief, a filter run against a sampler is a genuine consistency check — the NIS should average the number of measurement channels.

Kalman::Sampler sampler(&model, 12345);
sampler.Generate(1000);
Kalman::Filters::KF filter(&model);
filter.Forward(sampler.Measurements());

Note
Noise is drawn through a Cholesky factor of Q and R, so correlated noise is handled correctly; a covariance that is only positive semi-definite — a white-noise-acceleration block is exactly that — is jittered rather than rejected.
