Detailed Description

The toy model in C++: simulate a test sensor, filter it, save both.

Loads libKalmanPlugin_toy (toy_plugin.cc), which defines the cooling-coffee model, and never sees its class: the model is found by name in the factory. The program then

  1. simulates a test sensor — half an hour of thermometer readings of a cup that starts at 90 degC and cools at k = 0.002 /s — with the library's sampler and a fixed seed;
  2. runs the extended Kalman filter over the readings;
  3. writes toy_sensor.csv (time, true T, true k, reading) and toy_estimate.csv (time, estimated T and k with their sigmas).

examples/python/toy_sensor.py reads those two files, runs the same C++ model from Python on the same readings, and compares. 

make build && make examples
./var/build/bin/toy_sensor [output directory] [plugin library]
