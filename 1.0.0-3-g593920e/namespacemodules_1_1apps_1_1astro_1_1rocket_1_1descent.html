Corner arrays for a rocket drawn at ``(x, y)`` tilted ``th`` rad from vertical.

Returns a dict of ``(N, 2)`` point arrays — ``body`` (rectangle), ``nose`` (triangle) and,
when ``flame > 0``, a ``flame`` triangle out of the base. The body axis (nose direction)
maps to ``(−sin θ, cos θ)``, so positive ``θ`` leans the vehicle toward +x. ``anchor="base"``
(default) plants the **base** of the vehicle at ``(x, y)`` so it stands on the ground/pad at
that point (the physical offset from the centre of mass); ``anchor="com"`` centres it instead.

42def _rocket_shape(x, y, th, length, width, *, flame=0.0, nose=None, anchor="base"):
43 """Corner arrays for a rocket drawn at ``(x, y)`` tilted ``th`` rad from vertical.
44
45 Returns a dict of ``(N, 2)`` point arrays — ``body`` (rectangle), ``nose`` (triangle) and,
46 when ``flame > 0``, a ``flame`` triangle out of the base. The body axis (nose direction)
47 maps to ``(−sin θ, cos θ)``, so positive ``θ`` leans the vehicle toward +x. ``anchor="base"``
48 (default) plants the **base** of the vehicle at ``(x, y)`` so it stands on the ground/pad at
49 that point (the physical offset from the centre of mass); ``anchor="com"`` centres it instead.
50 """
51 hw = 0.5 * width
52 nose = 1.5 * hw if nose is None else nose
53 y0, y1 = (0.0, length) if anchor == "base" else (-0.5 * length, 0.5 * length)
54 c, s = np.cos(th), np.sin(th)
55 R = np.array([[c, -s], [s, c]])
56 def world(pts):
57 P = (R @ np.asarray(pts, float).T)
58 return np.column_stack([P[0] + x, P[1] + y])
59 parts = {
60 "body": world([(-hw, y0), (hw, y0), (hw, y1), (-hw, y1)]),
61 "nose": world([(-hw, y1), (hw, y1), (0.0, y1 + nose)]),
62 }
63 if flame > 0:
64 parts["flame"] = world([(-0.6 * hw, y0), (0.6 * hw, y0), (0.0, y0 - flame)])
65 return parts
