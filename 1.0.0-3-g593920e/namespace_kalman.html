◆ EngineKind

enum class Kalman::EngineKind
strong

Which inference algorithm a model wants, and which one an engine provides.

Every kind has a C++ engine. Combinatorial is an Extended step plus a track-finding search over an event (Kalman::Engines::Combinatorial::Find); Kalman::Filters::CKF is its leaf, since its input is not a time series.

The integer values are the contract with modules/framework/models/native.py (ENGINE_BY_INT): never renumber.

◆ StructureKind

enum class Kalman::StructureKind
strong

What a model is made of, which decides what a file can hold of it.

Maps: f() and h() are code. A file can name the model and carry its settings, not the model itself. This is the default: a model that says nothing is never written out as if its matrices were all of it. Matrices: the model is its constant F, H, B, L, Q, R. A file holds all of it. TimeVarying: the model is its matrices, and they change with time. A file holds all of it over a stated range of samples, as tables.
