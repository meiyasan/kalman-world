Detailed Description

Jacobian-linearised Kalman step for nonlinear models.

Propagates the mean through the true map f(x, u, t) and the covariance through its Jacobian F = df/dx, taken from Kalman::Model::Jacobian() — analytic when the model provides one, central differences otherwise. Likewise h and H = dh/dx on the measurement side.

On a linear model this reduces to the linear computation (the Jacobian of F x is F), so it is always a safe default when in doubt.
