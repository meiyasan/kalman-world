Detailed Description

One filtered (or smoothed) pass: time, state, covariance, measurement.

The output type of Kalman::Filter::Forward() / Backward(), and the counterpart of KalmanRecord on the Python side.

It is a plain value type and it draws nothing. Series() and Sigma() hand back the arrays a plot needs; turning those into a TGraph, a matplotlib axis or a CSV is the job of whoever integrates the library, because that is where the plotting dependency belongs. The +/- K sigma band is available here because it is the whole point of running a Kalman filter rather than a smoothing spline, and it is the first thing lost when estimates are shipped around as bare arrays.
