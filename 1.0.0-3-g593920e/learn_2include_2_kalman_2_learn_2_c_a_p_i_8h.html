Detailed Description

The C interface of libKalmanLearn.

Author
Marco Meyer <marco.nosp@m..mey.nosp@m.er@om.nosp@m.u.ac.nosp@m..jp>

What the Python package calls in libKalmanLearn. Same conventions as Kalman/CAPI.h: an int is 0 on success and -1 on failure, a pointer is NULL on failure, and kalman_learn_last_error() holds the message.
