Detailed Description

The classical IKF update: mu_j ∝ c_j · L_j.

Combines the Markov transition prior with the Gaussian innovation likelihood — Bayes' theorem, nothing more. Optimal when every model is a correctly specified Gaussian, and the right default in almost every case: it needs no training data, no export pipeline and no runtime dependency, and each update can be explained.

Reach for Kalman::Routers::Neural only when the regime structure is genuinely not Markov, or the switching signature is one a likelihood ratio cannot see.
