1"""Run the Kalman MCP server. ``python -m kalman.mcp`` / ``kalman-mcp``.
2
3stdio locally; set ``KALMAN_MCP_TRANSPORT=sse`` or ``streamable-http`` (+
4``KALMAN_MCP_HOST/PORT``, default ``127.0.0.1:8765``) to serve over HTTP. Set
5``KALMAN_API_URL`` to make this server a client of the REST API, which then
6owns the registry, the runs and the token checks.
7
8Over HTTP, clients send ``Authorization: Bearer <JWT>``. That is required
9whenever tokens can be checked — ``KALMAN_JWT_SECRET`` here, or a REST API that
10reports auth on — and a server on a network interface refuses to start with
11neither (see :func:`kalman.api.auth.check_server`).
12
13The ``mcp`` SDK is optional — absent, we print an install hint and exit 0 so
14the core is never blocked.
15"""

22 """``(auth_settings, verifier)`` when tokens can be checked, else ``(None, None)``."""
23 from ..api.auth import enabled
24 remote_auth = False
25 if backend.kind == "remote":
26 try:
27 remote_auth = bool(backend.health().get("auth"))

30 if not (enabled() or remote_auth):
