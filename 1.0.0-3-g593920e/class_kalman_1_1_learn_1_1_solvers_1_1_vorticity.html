Detailed Description

Batched pseudo-spectral 2-D vorticity solver on libTorch (CPU, CUDA, MPS).

Advances many vorticity fields at once, which is what an ensemble filter on a flow needs: one call steps every member. The equation is

dw/dt = -u.grad(w) - beta v + nu lap(w) + F

on a periodic grid: velocities and gradients in Fourier space, the products on the grid, 2/3-rule dealiasing, and any explicit Runge-Kutta scheme given by its Butcher tableau. With beta = 0 and a forcing this is the Kolmogorov flow; with beta and no forcing, the barotropic beta-plane.

It is the libTorch counterpart of Kalman::Solvers::Spectral, which steps one field at a time with the built-in FFT, and it replaces the Python Torch backend of kalman.framework.solvers.SpectralSolver.

On MPS (Apple GPUs) there is no double precision: fields are stepped in single precision there, in double everywhere else.

libTorch stays behind a pImpl. HasRuntime() says whether this build has it; without it the constructor throws.
