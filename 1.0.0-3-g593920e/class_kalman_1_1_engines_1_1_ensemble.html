Detailed Description

Perturbed-observation ensemble Kalman filter (Evensen).

The workhorse of high-dimensional data assimilation. The covariance is never formed during the analysis: N members carry it, and the gain is built from their anomalies —

P H^T = rho_xy o X' Y'^T / (N - 1) Y' = h(X)' (observation-space anomalies)
H P H^T = rho_yy o Y' Y'^T / (N - 1)
K = P H^T (H P H^T + R)^-1
X^a = X + K (z + eps - h(X)), eps ~ N(0, R) per member

Multiplicative inflation scales the anomalies before each analysis to make up for sampling error; optional localization tapers (rho_xy, rho_yy, e.g. Gaspari–Cohn of the state/observation distances) cut spurious long-range correlations from a small ensemble. Predict() and Update() hand back the ensemble mean and sample covariance so the record and the diagnostics are unchanged; Members() exposes the raw ensemble for workflows that never want the dense n x n.

Stateful, like Engines::Particle: it holds the ensemble across a forward pass and Kalman::Filter calls Reset() at the start of a run. No RTS smoother.

The random stream is engine-owned and seeded in the constructor — the RNG discipline that lets several filter variants run side by side without one changing another's draws. A caller that draws elsewhere (Python, whose numpy generator makes a seeded run repeatable) hands the standard normals in with SetNormals(), and the engine reads them in place of its own stream.

A model whose state is a field implements Engines::EnsembleModel beside Kalman::Model: the forecast and the observation of the whole ensemble at once, its localization tapers, and its process noise as a diagonal, so that nothing of size n x n is formed during a cycle.

Mirrors modules/framework/engines/ensemble.py.

void Kalman::Engines::Ensemble::SetNormals ( std::vector< double >  normals)

Standard normal draws to use in place of the engine's own stream.

Read in numpy's layout: a draw of rows values for each of the N members takes the next rows x N numbers as a row-major (rows, N) block, member s reading column s, as rng.standard_normal((rows, N)) does. The forecast draws n rows when Q is not zero, the analysis p rows (the channels present). The initial ensemble is not drawn from them (hand it in with SetMembers()). Running out throws.
