Detailed Description

The REST API of modules/rest/app.py, for the verbs Kalman::Net::Api serves.

Same routes, same bodies, same answers and the same status codes, so a client of the Python server (Unity, a dashboard, curl) talks to this one unchanged. The token is the Authorization: Bearer header; each route checks the scope the Python route checks. 

GET  /healthz                 GET  /whoami
GET  /catalog                 GET  /describe/{name}
GET  /models                  GET  /plugins          POST /plugins {name}
GET  /sources                 GET  /sources/{name}
GET  /events/cursor           GET  /events?since=&limit=
GET  /diagnostics/{run_id}
POST /filter {spec, data | source, query?, smooth?}
POST /forecast {spec, x0, P0?, steps?}
POST /sample {spec, duration, seed?, ...}        (this server only)
POST /mcp                                        (MCP over HTTP, JSON-RPC)

The routes of the Python server that need Python (plots, providers, OSSE, control, authoring, tokens) answer 501 naming it.
