Detailed Description

The ensemble Kalman filter — Kalman::Filter driven by Engines::Ensemble.

Forward-only: Backward() throws. Members() reaches the engine for the ensemble, the inflation and the localization tapers. Mirrors modules/framework/filters/enkf.py.

Forward() records what every filter records, the mean and the covariance of each step. A field of n cells makes that covariance n x n, which a data- assimilation run never wants: Cycle() runs the same forecast and analysis steps and keeps the means and the spread only (the loop of the Python TwinExperiment).
