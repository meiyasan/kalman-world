Detailed Description

A tanh multilayer perceptron with a softmax head, evaluated directly.

The inference half of modules/framework/routers/nn/mlp.py, which is Linear → tanh → Linear → tanh → Linear → softmax. Training stays in Python, where Torch and the optimiser are; this evaluates the finished weights.

Its reason to exist is optionality. Kalman::Routers::NN::Onnx is the general path — it runs a graph exported from any of the Python architectures — but it needs ONNX Runtime. This one needs nothing, so a build with no optional dependencies at all still has a working learned router rather than only a declaration of one.

Kalman::Routers::NN::MLP mlp;
mlp.AddLayer(W1, b1); // (hidden, d_in)
mlp.AddLayer(W2, b2); // (hidden, hidden)
mlp.AddLayer(W3, b3); // (n_modes, hidden)
Kalman::Routers::Neural router(&mlp, 5);
