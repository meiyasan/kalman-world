Detailed Description

Data-driven intensity-tendency model — the ML elaboration on the physics.

Ridge regression of ``dI/dt`` on environmental predictors
``[sst_warmth, shear, I, 1]`` (the toy analogue of the operational **SHIPS**
statistical intensity scheme, which regresses on ~20 predictors).  The
physics tracker leaves intensity as persistence; this *learns* the
SST/shear→intensification relationship from past storms and plugs into
:class:`StormModel` via :meth:`as_intensity_fn`.

Deliberately dependency-free (numpy least squares) so it runs anywhere; a
torch MLP is the drop-in scale-up when the relationship is nonlinear.

Fit on a list of truth tracks ``(T, 5)`` — builds ``(features, dI/dt)``
pairs from consecutive intensities and their environment.  Features are
**standardised** before the ridge solve (they span very different
scales: SST ~0–30, shear ~3–30, intensity ~15–120), so no predictor is
implicitly penalised more than another.

Steps that end at or below ``floor`` [kt] are left out: a dissipated
storm is held at that value (see :func:`synthetic_steered_track`), so
its intensity change there says nothing about the tendency.

574 def fit(self, tracks, dt_hours=6.0, floor=15.0):
575 """Fit on a list of truth tracks ``(T, 5)`` — builds ``(features, dI/dt)``
576 pairs from consecutive intensities and their environment. Features are
577 **standardised** before the ridge solve (they span very different
578 scales: SST ~0–30, shear ~3–30, intensity ~15–120), so no predictor is
579 implicitly penalised more than another.
580
581 Steps that end at or below ``floor`` [kt] are left out: a dissipated
582 storm is held at that value (see :func:`synthetic_steered_track`), so
583 its intensity change there says nothing about the tendency."""
584 X, y = [], []
585 for tr in tracks:
586 tr = np.asarray(tr, float)
587 for k in range(len(tr) - 1):
588 if tr[k + 1, 4] <= floor:
589 continue
590 lon, lat, I = tr[k, 0], tr[k, 1], tr[k, 4]
591 sst, shear = self.env(lon, lat)
592 X.append(self._features(sst, shear, I))
593 y.append((tr[k + 1, 4] - I) / dt_hours)
594 X, y = np.asarray(X), np.asarray(y)
595 self._mu, self._sd = X.mean(0), X.std(0) + 1e-9
596 Xs = np.column_stack([(X - self._mu) / self._sd, np.ones(len(X))])
597 A = Xs.T @ Xs + self.ridge * np.eye(Xs.shape[1])
598 self.coef_ = np.linalg.solve(A, Xs.T @ y)
599 return self
