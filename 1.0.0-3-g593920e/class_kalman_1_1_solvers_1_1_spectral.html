Detailed Description

Pseudo-spectral 2-D field solver: FFT discretization, composed time march.

Owns the spatial part — the transform, the ik operators, the 2/3-rule dealiasing mask — and delegates the time march to the composed Kalman::Integrator applied to the spectral field. A subclass supplies the physics through RHSHat(): the spectral d(omega_hat)/dt. This class is domain-agnostic; a Kolmogorov flow or a barotropic model is an application.

Spectral discretization requires a regular periodic mesh; bounded or irregular grids are the job of the finite-difference kind. Wavenumbers scale as 2 pi / L, so L = 2 pi reproduces integer wavenumbers exactly.

Mirrors modules/framework/solvers/spectral.py (the numpy path; the torch backend is a Python concern).
