Detailed Description

The system — WHAT is being estimated.

A model owns the dynamics and the observation map, and nothing else: no run state, no algorithm, no workflow. It answers, for a given time t:

x_{k+1} = f(x_k, u_k, t) the dynamics
z_k = h(x_k, t) the observation

together with the matrices the estimator needs — the transition F, the observation H, the control map B, the process-noise coupling L, and the covariances Q (process) and R (measurement).

The class is concrete and linear out of the box: construct it with dimensions, set F/H/Q/R, and the default f()/h() are F x + B u and H x.

For a nonlinear system, subclass and override f() and/or h(). The Jacobians are then obtained by central differences unless you also override Jacobian() / JacobianH() with the analytic ones — tell the base which by calling SetAnalyticJacobian(false) in your constructor.

For a system given as an ODE, override Derivative() with xdot = f(x, u, t) and call UseContinuousDynamics() in your constructor: the default f() then advances the derivative one sample with the model's Kalman::Integrator (DefaultIntegrator(), RK4 unless declared otherwise, in Substeps() substeps), which is the ODE counterpart of a PDE model binding a Kalman::Solver. The integrator is declared through its kind and resolved on first use, so a model never constructs one — and a custom scheme can still be handed in through SetIntegrator(std::shared_ptr<Integrator>).

Note
This class is the contract, not a catalogue. libKalman ships no physics: a pendulum, a drift chamber or a power grid is an application, and applications are built on top of this header, not inside it. The equations live where the domain knowledge lives.

◆ TimeUnit()

double Kalman::Model::TimeUnit ( ) const
inline

The unit this model counts time in, in seconds (1 by default).

A storm model steps in hours and a space model in kiloseconds: their sample rate is per that unit, not per second. Stating the unit is what lets a reader (the kalman program) give the rate in hertz. It changes no arithmetic.
