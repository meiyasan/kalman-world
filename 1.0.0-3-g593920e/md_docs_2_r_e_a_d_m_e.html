Kalman World documentation

Kalman-family estimation in C++ and Python: composable contracts in kalman.framework and libKalman, domain applications in kalman.apps and libKalmanApps, and one JSON facade (kalman.api) exposed over REST and MCP so humans, scripts and agents all drive the same code.

Also in this repository

  • ../share/notebooks/ — 16 executed, output-bearing notebooks, from 00_Kalman101 to 14_StormTracking. These are the narrative documentation; these pages are the reference. Trained artefacts a notebook would otherwise rebuild on every run (the neural controllers and routers of 12_KalmanAI) are kept under share/notebooks/cache/<notebook>/ by kalman.helpers.cached_fit; delete a file, or set KALMAN_CACHE_REFRESH=1, to retrain.

Conventions used in these pages

  • On disk the package is modules/; installed, it is **kalman**. Always import kalman.… (package-dir = {"kalman" = "modules"} in pyproject.toml).
  • $ marks a shell command; >>>-free code blocks are copy-pasteable Python.
  • Every example in these pages was executed against the current tree.
