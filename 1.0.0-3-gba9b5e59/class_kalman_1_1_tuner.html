Detailed Description

Retunes the filter's own noise model as it runs; commands nothing.

A controller acts on the system: it computes the command u. A tuner acts on the filter: once per step, with the innovation in hand, it adjusts the model's Q or R (a filter that is surprised trusts its measurements more; a process noise that no longer explains the innovations is rescaled). The two are different roles, and a filter takes one of each:

Kalman::Controllers::LQR lqr(&model);
Kalman::Tuners::AdaptiveQR tune(&model);
filter.Forward(measurements, lqr, tune); // a command from lqr, the noise retuned by tune
filter.Forward(measurements, tune); // no command, the noise retuned
