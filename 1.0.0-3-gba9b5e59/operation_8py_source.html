1"""
2The base of the model operations: a model built from other models.
3
4``joint``, ``observe``, ``lag``, ``compose`` and ``route`` each take models and
5give back a model. The work is done by a C++ class (``Kalman::Models::Joint``
6...) that wraps the inner models' C++ handles; the Python class is a
7:class:`~.native.NativeModel` around it, so ``f``, ``h``, the Jacobians and the
8noise are the C++ model's and a filtering pass runs in ``Kalman::Filter``.
9
10An inner model reaches C++ through :func:`~.native.handle_of`: as it is when it
11is C++ already, as its counterpart, as its matrices, or through callbacks to its
12Python methods.
13"""
