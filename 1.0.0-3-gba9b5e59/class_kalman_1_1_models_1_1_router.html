Detailed Description

Several models of one system, with a probability on each.

A system that changes regime (an aircraft that cruises, then turns; a storm that runs straight, then recurves) is described by one model per regime, the modes. They share the state and the measurement: every mode means the same thing by x and by z. What changes between them is the motion or the noise. A Markov matrix Pi says how likely the system is to go from mode i to mode j in one step, and the model carries a probability mu on each mode.

The model holds the modes, Pi and the initial probabilities. The estimation is done by the interacting engine (Kalman::Engines::Interacting, this model's default engine; the Interacting Multiple Model filter of the literature), run by a plain Kalman::Filter:

auto modes = Kalman::Route({cruise, turn}, Pi);
Kalman::Filter filter(modes.get());
Kalman::Record record = filter.Forward(zk); // the combined estimate

Seen as one model, it answers f, h and its coefficients with those of its leading mode: the most probable one, which the engine keeps up to date (the first of the highest initial probabilities before any data). Its initial state is the modes', combined with the initial probabilities.

Who decides the probabilities at each step is a Kalman::Routers::Router, the decision layer (Bayesian by default; a rule, a network, a blend).

A parameter of a mode is <mode>.<name>, the mode being called by its model's name (numbered from the second that shares one) or by the names given. The modes are shared, not copied.
