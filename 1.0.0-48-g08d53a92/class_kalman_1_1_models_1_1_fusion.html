Detailed Description

A model read by one more sensor: several sensors on the same state.

The state and its dynamics are the inner model's, untouched. The measurement grows by the channels of the added Kalman::Sensor,

z = [ h_inner(x, t) ; g(x, t) ] R = diag(R_inner, R_sensor)

and one filter update weighs every sensor by its noise: that is sensor fusion. The sensor reads through a function g (its Jacobian given, or differenced with the inner model's scheme) or a matrix G. With a matrix on an inner model that is its matrices, the result is still its matrices: H(t) is the inner one with G below it, and the linear engine runs it.

Sensors() lists the inner model's sensors, then the added one, so adding sensors one after another gives one flat list.

This is not Models::Composite, which puts models with their own states side by side: here a second instrument reads the same state (a Doppler radar on a tracked shell, a second camera).

The inner model is shared, not copied; it receives this model's sample rate before each evaluation, and its named parameters are this model's, so the operations nest (a parameter of the inner model can be estimated through Models::Joint around this one).
